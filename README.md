# AI-Assisted Coding: A Beginner's Manual

A plain-English, step-by-step guide to writing code with AI for free. Written
for beginners — nurses, authors, small-business owners, and anyone who has
never opened a terminal. No condescension, no secrets required, no credit card
needed.

**Published by Asdale Dynamics, LLC** (Indiana, formed October 2026).
Asdale Dynamics makes beginner-friendly AI education, books, guides, and
practical open-source tools. Learn more about the author's work at
[dylanasdale.github.io](https://dylanasdale.github.io) and in *The Massive AI
Manual*.

## No secrets, ever

This guide never asks for API keys, passwords, or personal data. None of the
code here contains secrets. If you share code with an AI, strip out keys and
private information first.
