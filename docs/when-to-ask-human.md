# When to Ask a Human

AI is a helpful assistant, but it is not a replacement for human judgment —
especially when you're learning. This guide helps you recognize when to step
away from the AI and ask another person.

## Signs it's time to ask a human

Ask a human (a friend, teacher, coworker, or online community) when:

1. **You've asked the AI three times and the problem isn't fixed.**
   The AI may be going in circles. A fresh human perspective often spots the
   issue in seconds.

2. **The code does something you can't explain.**
   If you read the code (see reading-ai-code.md) and still don't know what a
   section does, don't run it. Get someone to walk through it with you.

3. **The task involves money, passwords, health data, or other people's private
   information.**
   AI can mishandle sensitive data. A human can help you design something safe.

4. **You're changing something important you can't afford to lose.**
   Before you write a script that renames 500 files or edits your budget
   spreadsheet, have someone review it.

5. **The AI is suggesting terminal commands you don't trust.**
   See terminal-safety.md. When in doubt, ask a human before running `sudo`,
   `rm`, or anything that installs software.

6. **You feel stuck, frustrated, or embarrassed.**
   Feeling stuck is normal. Asking for help is a skill, not a weakness. Every
   experienced programmer asks other people questions constantly.

## Who to ask

- A friend or family member who knows a little coding
- Online communities: Stack Overflow, Reddit (r/learnpython, r/learnprogramming),
  Discord servers for your language or tool
- Your local library or community college — many offer free or low-cost
  intro classes
- The AI itself can help you *formulate* a good question to ask a human

## How to ask a good question

Good questions get good answers fast. Include:

- **What you're trying to do** (one sentence)
- **What you've tried** (the code, the commands)
- **What happened** (the full error message, or "it did nothing")
- **What you expected** (the correct behavior)
- **Your skill level** ("I'm a beginner, please keep it simple")

Example:

> I'm trying to total up a file of expenses in Python. I wrote this script:
> 
> ```python
> [code]
> ```
> 
> When I run it I get:
> 
> ```
> [error]
> ```
> 
> I expected it to print a number. I'm a beginner, so please explain simply.

## AI is for drafting; humans are for deciding

Use the AI to generate ideas, write first drafts, and explain concepts. Use a
human to:

- Review code before you run it on important data
- Help you judge whether an AI suggestion is safe
- Encourage you when you're stuck
- Teach you concepts the AI explains poorly

## Your ask-a-human checklist

- [ ] I've tried the AI at least twice on this problem
- [ ] I can't explain some part of the code
- [ ] I'm not sure the code is safe
- [ ] I feel stuck or frustrated

If you checked any box, it's a good time to ask a human.
