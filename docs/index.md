# AI-Assisted Coding: A Beginner's Manual

Welcome. This manual teaches you how to write code with AI, for free, starting
from zero. You don't need a computer science degree, a credit card, or prior
experience. If you can read and type, you can follow along.

## How to use this manual

Read the pages in order, or jump to the topic you need. Each page is written in
plain English, step by step, never condescending. Try things as you go — the
best way to learn is by typing commands and reading code.

| Page | What you'll learn |
|------|-------------------|
| [Reading AI-written code](reading-ai-code.md) | Understand code before you run it |
| [Fixing errors](fixing-errors.md) | Read error messages and work with the AI |
| [Terminal safety](terminal-safety.md) | Use the command line without breaking things |
| [Prompts that work](prompts-that-work.md) | Get good code from free AI |
| [When to ask a human](when-to-ask-human.md) | Know the limits of AI code |
| [First project walkthrough](first-project.md) | Build a real tool, step by step |
| [Glossary](glossary.md) | Plain-English definitions |
