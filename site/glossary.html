Glossary

← Back to manual  |  Published by Asdale Dynamics, LLC

Plain-English definitions for terms used in this guide. If you see a word you don't recognize, look it up here.

AI
Artificial intelligence. Software that can generate text, code, images, or other content based on patterns it learned during training.
AI-written code
Code produced by an AI assistant rather than typed by a person. It may be correct, partly correct, or wrong — always read it before running.
Argument
A value you pass to a program or function when you run it. Example: in python expense-total.py expenses.txt, expenses.txt is an argument.
Browser
An app for viewing websites (Chrome, Firefox, Safari, Edge).
Bug
A mistake in code that makes it behave incorrectly.
Command line / terminal / shell
A text-based way to control your computer by typing commands instead of clicking.
Commit
A saved snapshot of your project's files in Git, with a message describing what changed.
Error message
Text the computer prints when something goes wrong. It usually tells you what failed and where.
File path
The address of a file on your computer, like documents/expenses.txt or C:\Users\Dylan\expenses.txt.
Folder / directory
A container for files and other folders.
Function
A named block of code that does one thing and can be reused.
Git
A tool that tracks changes to your files over time, so you can undo mistakes and see history.
GitHub
A website that hosts Git projects and lets you share code.
Import
Bringing in code from another file or library so you can use it.
Library / module / package
Code written by someone else that you can use in your own program (e.g., Python's json module).
Linear / bottom-up reading
Reading an error message from the last line up, because the actual problem is usually at the bottom.
Markdown
A simple way to format text using symbols like # for headings and ** for bold. Files end in .md.
Prompt
The message you send to an AI to ask it to do something.
Python
A popular programming language known for being readable and beginner-friendly.
README
A file (usually README.md) that explains what a project is and how to use it.
Repository / repo
A folder (or GitHub project) whose changes are tracked by Git.
Script
A short program, usually saved in one file, that does a specific task.
Static site
A website made of HTML files that don't need a server or database. You can open the files directly in a browser.
Traceback
The detailed list of function calls in a Python error message, ending with the actual error.
Variable
A name that refers to a value, like total = 0.
Virtual environment
An isolated folder for a Python project so its installed libraries don't affect the rest of your computer.
Walkthrough
A step-by-step guide to building something.
