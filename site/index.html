Welcome

This manual teaches you how to write code with AI, for free, starting from zero. You don't need a computer science degree, a credit card, or prior experience. If you can read and type, you can follow along.

Read the pages in order, or jump to the topic you need. Each page is written in plain English, step by step, never condescending. Try things as you go — the best way to learn is by typing commands and reading code.
